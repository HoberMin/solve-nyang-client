# 😻 솔브냥 - 알고리즘 풀고 키우는 나만의 고양이!

===============================

### 🧩 `solved.ac` 문제 풀이로 냥코인을 획득하고, 🐾 귀여운 고양이들을 수집해 특별한 리드미를 꾸며보세요!

## ✨ 주요 기능

- **냥코인 획득**: `solved.ac` 문제 풀이 기록을 기반으로 난이도에 따라 냥코인을 지급합니다.
- **다양한 고양이 컬렉션**: 냥코인으로 귀여운 고양이를 뽑아 나만의 컬렉션을 완성하세요.
- **고양이 판매 및 경매장**: 수집한 고양이를 판매해 추가 냥코인을 확보하세요.
- **나만의 리드미 꾸미기**: 원하는 고양이를 선택해 깃허브 리드미를 꾸밀 수 있습니다.
- **실험실**: 출석 체크, 미니게임 등 새로운 기능을 미리 체험해 보세요.

## 🪙 냥코인 모으는 방법

- **알고리즘 문제 풀이**: 백준에서 `solved.ac` 계정 연동 후 문제를 풀면 냥코인을 지급합니다.
- **높은 티어 문제 도전**: 난이도가 높을수록 더 많은 냥코인을 획득할 수 있습니다.
- **출석체크**: 매일 알고리즘 문제를 풀면 추가 냥코인을 얻을 수 있습니다.

---

## 🐾 고양이 수집의 재미

- **랜덤 뽑기**: 어떤 고양이가 나올지 기대되는 재미!
- **등급별 희귀 고양이**: 다양한 등급의 고양이를 모아보세요.
- **나만의 고양이 도감**: 수집한 고양이를 한눈에 확인할 수 있습니다.

---

## 🎨 깃허브 리드미를 특별하게

- **간편한 이미지 생성**: 수집한 고양이를 조합해 나만의 리드미 이미지를 만드세요.

- **배경 구매**: 냥코인으로 배경 상점에서 개성있는 배경을 구매할 수도 있어요.
- **링크 복사 & 적용**: 생성된 이미지 링크를 깃허브 리드미에 붙여넣으면 끝!

---

## 🚀 솔브냥 시작하기

1.  [솔브냥 홈페이지](https://www.solve-nyang.com/) 방문
2.  `solved.ac` 문제 풀이로 냥코인 획득
3.  모은 냥코인으로 고양이를 뽑아 컬렉션 완성
4.  리드미 이미지를 생성해 깃허브 프로필을 꾸미기
